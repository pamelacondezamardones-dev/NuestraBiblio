REGLAS DE FIRESTORE PARA NUESTRABIBLIO

Estas reglas deben coincidir con la colección `libros` que utiliza index.html.
Si ya publicaste estas mismas reglas con los UID reales, NO necesitas cambiarlas.

Sustituye UID_PAMELA y UID_CLAUDIO por los identificadores de Authentication > Usuarios.
No pegues contraseñas. No publiques tus UID reales en GitHub.

rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /libros/{libroId} {
      allow read, write: if request.auth != null
        && request.auth.uid in [
          'UID_PAMELA',
          'UID_CLAUDIO'
        ];
    }
    match /{document=**} {
      allow read, write: if false;
    }
  }
}

Firebase Console > Firestore > Reglas > Publicar.
